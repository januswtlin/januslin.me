# Reports

Dated outputs from recurring work and incidents. Append-only; never edit a past report except to fix a factual error (note the fix at the bottom).

- `seo-YYYY-MM.md`: monthly SEO/AEO audit (`docs/seo-aeo.md` → Periodic audit)
- `audit-YYYY-MM-DD.md`: independent audits (T18 and later)
- `incident-YYYY-MM-DD.md`: incident notes (`docs/operations.md` runbooks)
- `upgrade-YYYY-MM.md`: optional monthly upgrade summary
