# Turn on Cloudflare Zero Trust
Where: the Cloudflare dashboard · Time: about 10 min

1. Cloudflare → Zero Trust. If it was never enabled, complete the onboarding on the **Free** plan (it may ask for a payment method; the plan costs nothing).
2. Tell the coordinator in the session (not in an issue: it is personal data) which email address the "Author only" policy should allow.

## Check
Expected: Zero Trust → Settings shows the Free plan. Reply with the seat limit it shows and "email given in the session".
