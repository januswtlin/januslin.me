# Framework guide (staging)

This directory is a temporary home for the design of a project-independent guideline: how one
human supervisor and several AI agents build and run software. It lives on the branch
`claude/software-dev-framework-ai-nauzuf` only and is not meant to be merged into this site's
`main`. It moves to a dedicated repository once the author creates one.

| File | What it is |
|---|---|
| `design.md` | The framework record: decisions, chapter structure, reading paths. Canonical, English. |
| `review-log.md` | The review debate on `design.md`, round by round, with the outcome. |

Later: `en/` (the guide, canonical) and `zh-tw/` (a translation for scanning).
